Decode any published Google Tag Manager container.

Fetch a live container by ID, or paste the raw gtm.js source / a container export JSON. Everything is parsed locally in this page — nothing is uploaded anywhere.

01Fetch by container ID

Loads googletagmanager.com/gtm.js?id=… directly. If the browser blocks the cross-origin request, a fallback route appears below.

Manual route (30 seconds):
  1. Open the gtm.js URL in a new tab
  2. Select all (Ctrl/Cmd A) and copy
  3. Paste into the box on the right and hit Parse

02Paste source or export

Accepts raw gtm.js contents (auto-extracts the data object) or a GTM container export (Admin → Export Container). Format is auto-detected.

Privacy: parsing happens 100% in your browser. No container data leaves this page. The optional CORS-relay fetch only ever touches the public gtm.js file.
